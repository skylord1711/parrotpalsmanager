Commands

All available slash commands for ParrotPals Bot. Use / in Discord to see them.

🔴 Stream

/go-live

Announce your TikTok stream to the server with an @everyone ping. Optional message field for what you're playing.
Usage: /go-live [message]
🔗 Social

/socials

Display the streamer's TikTok link in a clean embed.
⚡ Utility

/ping

Check the bot's current WebSocket latency in milliseconds.
Response: Pong! 32ms
🛡️ Moderation

/kick

Kick a member from the server. Logs to the mod channel if configured. Requires Kick Members permission.
Usage: /kick @user [reason]
🛡️ Moderation

/ban

Ban a member from the server. Logs to the mod channel. Requires Ban Members permission.
Usage: /ban @user [reason]
🛡️ Moderation

/warn

Issue a warning to a member. DM's the user the reason. Tracks total warnings. Requires Moderate Members permission.
Usage: /warn @user [reason]
🛡️ Moderation

/warnings

View all warnings for a specific member, with reason, moderator, and date.
Usage: /warnings @user
🛡️ Moderation

/unwarn

Remove a specific warning by its ID number. Use /warnings to find the ID.
Usage: /unwarn 3
🛡️ Moderation

/clear

Bulk delete recent messages in the current channel (max 100). Requires Manage Messages permission.
Usage: /clear 20
🛡️ Moderation

/slowmode

Set the slowmode delay in seconds for the current channel. Set to 0 to disable. Requires Manage Channels permission.
Usage: /slowmode 5
🛡️ Moderation

/timeout

Timeout (mute) a member for a specified number of minutes. Requires Moderate Members permission.
Usage: /timeout @user 10 [reason]
⚡ Utility

/commands

List all available slash commands in Discord with a quick overview.

🎫 Ticket Commands

🎫 Tickets

/ticket-panel

Send the ticket creation panel (buttons/select menu) to the current channel. Requires Administrator.
🎫 Tickets

/close

Close the current ticket channel. Generates a transcript and logs the action.
🎫 Tickets

/claim

Claim a ticket to show you're handling it. Only available to support roles.
🎫 Tickets

/unclaim

Release your claim on a ticket so another staff member can handle it.
🎫 Tickets

/add

Add a user to the current ticket channel so they can view and participate.
Usage: /add @user
🎫 Tickets

/remove

Remove a user from the current ticket channel. Requires support role.
Usage: /remove @user
🎫 Tickets

/rename

Rename the current ticket channel.
Usage: /rename new-name
🎫 Tickets

/blacklist

Blacklist a user from creating tickets. Requires Administrator.
Usage: /blacklist @user [reason]
🎫 Tickets

/unblacklist

Remove a user from the ticket blacklist. Requires Administrator.
Usage: /unblacklist @user
